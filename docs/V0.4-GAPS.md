## NOT covered — still open
1. **Snap/Docker collectors fail silently.** src/collectors.rs still runs
   `timeout 5 snap list` / `timeout 5 docker images` and maps any failure to an
   empty vec. Daemon down, socket permission denied (user not in docker group),
   or a slow snapd all render as "0" — indistinguishable from genuinely none
   installed, and the Software pane's detail sections vanish entirely when empty.
   This is exactly the silent degraded mode Dickles banned. Fix: surface state
   explicitly (not installed / daemon unreachable / permission denied / N found),
   and always render the section with that state. Verify on the Omarchy box as
   his user: Prowlarr runs in Docker there (localhost:9696 per the rebuild kit),
   so a 0-images result while containers exist proves the permission path.
2. **Copy & Share lag.** Dickles reported serious lag on v0.3's Copy for Forum.
   The v0.4 sheet still calls share_copy per click, and the backend
   (gui/src-tauri/src/main.rs render_report / sanitized_copy) clones the full
   profile JSON, sanitizes, and re-renders the whole Markdown report
   synchronously on every click — no caching. Likely lag source (code-grounded,
   not profiled). Fix: render once per profile load, cache per kind, invalidate
   on refresh; show a busy state on the button meanwhile.
